Shipping

Delivery is priced per order from the India Post Speed Post tariff — parcel weight (from package size and what is in the cart) against the distance to the customer's PIN code. Set the studio's dispatch PIN, packaging allowance and per-category weights here, then test a real PIN below.

Products

Manage the shop catalogue — add, edit, or remove products.

Orders

View e-commerce orders, update fulfilment, edit details, or create an order manually and send a payment link.

Enquiries

Every lead the site collects — contact form, workshop bookings, and newsletter signups. Saved even when the notification email fails.

Workshops

Edit Experience, Corporate, and Curated workshops.

Blogs

Write and edit the blog posts shown on the public site. They also feed the Quick Reads strip on the home page.

All images

Every image slot on the public site, grouped by page in the same order as the site menu — so a page that is still missing artwork is easy to spot. The same slots also appear on each page above.

Gallery

The central media library. Every uploaded image lives here with a title, description, and tags. Mark an image Public to feature it in the consumer design gallery and its SEO page.

Store-wide sale

One site-wide percentage off every product, applied automatically (no code). When live, a banner shows across the site and prices are struck through. If a customer also has a coupon, the bigger discount wins.

Off

Discount codes

Create coupon codes — percentage off (with an optional cap) or a flat amount off. Customers enter them in the cart.

Manage who can sign in to this panel. New admins log in with their email and password.
